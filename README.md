# PLP Python Week 4 Assignment

This repository contains my solutions to the Week 4 Python functions assignment.

## Files

* `welcome.py` — Defines a function that returns a welcome message for a given name.
* `toolbox.py` — Contains three functions: `double()`, `is_pass()`, and `greet()`.

## Reflection

The `greet()` function was the hardest for me to understand because it uses a default parameter value. I learned that Python uses the default greeting when no alternative is provided, but allows a different greeting to be supplied when calling the function.
